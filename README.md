# Слово за словом

Первый десктопный блок сайта по Figma, фрейм `32:162`:
https://www.figma.com/design/OarrPZzXW8mB20be3jmGoU/?node-id=32-162

## Локальный просмотр

Без установки зависимостей:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4173/ . Также можно открыть `index.html` напрямую.

## Принципы

- Базовая ширина макета: 1920 px. `1rem = ширина окна / 120`, то есть 16 px при ширине 1920 px. Типографика, карточка, кнопки, внутренние отступы и иллюстрация масштабируются пропорционально.
- Высота hero определяется пропорцией 1920:1585, без минимальной высоты окна.
- Исключение из масштабирования — заданные внешние отступы от окна: 40 px.
- Меню фиксировано снизу по центру окна. Карточка находится в обычных координатах документа, с привязкой к нижнему краю первого окна через контейнер высотой 100svh.
- Иллюстрация изначально поднята на 100 px при базовой ширине 1920 px (6.25rem), а при скролле получает дополнительное смещение `-0.2 × scrollY`: суммарная скорость относительно окна — 120%. Она не масштабируется дополнительно и не обрезается по ширине. Открывающееся снизу пространство заполнено цветом страницы.
- Отступ между логотипом и H1 — 24 px при базовой ширине 1920 px (1.5rem); остальные отступы в CTA-блоке — 40 px (2.5rem). SVG занимает всю ширину своего масштабируемого контейнера и центрируется вместе с ним.
- Полоса прокрутки скрыта средствами CSS; нативная прокрутка колесом, трекпадом и клавиатурой сохранена.
- Весь текст использует локальный Medeo Sans Variable. Фото скачано из макета Figma, иллюстрация и логотип взяты из исходных файлов проекта.
- Hover-состояния соответствуют Figma; клавиатурный фокус виден. При `prefers-reduced-motion` параллакс отключён.
- Пункты меню содержат якоря будущих разделов. Сейчас свёрстан только hero: целевые разделы ещё не добавлены. Кнопка Telegram открывает существующий контакт проекта.
- Мобильная компоновка пока не разработана.

## Оптимизация иллюстрации

Исходный `hero-section-img.jpg` (3840 × 3170, 6 974 473 байта) сохранён для дальнейшей работы. Сайт загружает WebP с качеством 92:

| Ширина | Размер файла |
| --- | ---: |
| 1920 px | 310 606 байт |
| 2880 px | 532 996 байт |
| 3840 px | 775 664 байта |

Полное разрешение сохранено в старшем варианте; его вес уменьшен на 88,9%. Сжатие с потерями. `srcset` и `sizes="100vw"` позволяют браузеру выбирать размер с учетом ширины окна и плотности пикселей. Изображение первого экрана загружается приоритетно, без lazy loading.

Для повторной генерации установить Pillow и выполнить `python3 tools/optimize-images.py`.

## Файлы

- `index.html` — разметка.
- `styles.css` — fluid-масштабирование и оформление.
- `hero.js` — параллакс.
- `assets/profile.png` — фото для карточки.

Страница работает без сборщика, сторонних библиотек, аналитики и внешних шрифтов.
